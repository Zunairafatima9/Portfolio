# Zunaira Fatima Portfolio

A lightweight, responsive personal portfolio inspired by the clean editorial structure of the reference portfolio.

## Deploy with GitHub Pages

1. Create a new public repository named `ZunairaFatima9.github.io` (or any repository you prefer).
2. Upload `index.html`, `style.css`, `script.js`, and `resume.pdf`.
3. In GitHub: **Settings → Pages → Deploy from branch → main → /root**.
4. Save and wait for GitHub Pages to publish the site.

## Customize

- Replace `resume.pdf` with your latest PDF resume.
- Add project screenshots to the project cards if desired.
- Update LinkedIn URL if your public profile URL is different.
